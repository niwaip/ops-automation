## 目录说明

- `design/`
  当前设计文档入口。`v4` 是唯一实施基线，`v2`、`v3` 和 `history/` 仅作历史参考。
- `runbook/`
  面向排障、验证和阶段性落地的操作文档。
- `memory/`
  用于记录项目执行方法、导入规则和长期约定。
- `artifacts/`
  存放样例产物、验证结果和 UI 检查素材。
- `skills/`
  存放面向运行时或开发者的 Skill 资料。

## 整理原则

- 优先以代码现态为准，不再把旧规划文档当成当前真相来源。
- 历史版本文档保留版本目录，不混入当前实施入口。
- 无命名规则的草稿、重复副本、无明确归属的临时材料应及时清理。
