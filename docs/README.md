## 目录说明

- `design/`
  当前设计文档入口。只保留系统描述、项目描述和功能概要；历史材料统一收敛到 `archive/` 与相关专题归档中。
- `runbook/`
  面向排障、验证和阶段性落地的操作文档。
- `artifacts/`
  存放样例产物、验证结果和 UI 检查素材。
- `skills/`
  存放面向运行时或开发者的 Skill 资料。

## 整理原则

- 优先以代码现态为准，不再把旧规划文档当成当前真相来源。
- 历史材料集中归档，不混入当前实施入口。
- 无命名规则的草稿、重复副本、无明确归属的临时材料应及时清理。
