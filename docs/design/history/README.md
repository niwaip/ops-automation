# History

本目录保存项目早期设计资料，作为历史参考与演进背景说明。

这些文件的价值在于：

- 记录项目最初以浏览器自动化平台为中心的设计思路
- 保留需求原点、术语、旧版目录规划和阶段性想法
- 帮助后续团队理解为什么会从 `Browser Control Plane` 演进到 `Enterprise Skill Platform`

这些文件的限制在于：

- 不再与当前代码结构一一对应
- 不再作为当前架构与服务拆分的主依据
- 部分文件存在重复命名、草稿格式和历史残留内容
