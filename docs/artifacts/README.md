# Artifacts 导航

`artifacts/` 用于存放样例产物、验证结果和 UI 检查素材，不是正式设计文档目录。

当前子目录说明：

- `misc/`
  模板、样例脚本和测试用输入文件。
- `validation/`
  当前仍可直接参考的构建与验证结果样本。
- `ui/`
  当前仍可直接参考的界面检查素材。
- `archive/`
  一次性联调结果、历史截图导出和缺少业务上下文的旧样本归档。

使用原则：

- 该目录中的文件主要服务于验证、演示和调试。
- 无法说明来源、时间和用途的结果文件，不应继续留在主目录。
- 若某份产物已经失去用途，应优先清理，而不是继续堆积在正式文档目录中。
