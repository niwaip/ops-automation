# 标准柱状图交付闭环落地验证

本轮新增 `spreadsheet_chart_delivery.py`（状态编排、按轮次目录、来源核验及唯一产物发布）和
`spreadsheet_chart_renderer.py`（离线SVG渲染及结构/数据/几何验收）。在原agent loop和runner做小入口接入，
未将渲染、验收、发布逻辑继续堆进原有大文件。现有未提交改动保留。

## 行为

- 单表分组求和＋标准柱状图：模型只规划查询，核算证据完整后由内置渲染能力生成，不再依赖模型写HTML。
- sessionId/turnId独立目录，包含核验数据快照、输出、manifest；共享index.html不会参与查找或被覆盖。
- 生成→验收→发布有明确状态；最多2次渲染修复，复用已核算数据。
- 最终HTML通过后复制为唯一artifact文件名，现有下载API直接定位该文件；发布后复核哈希。
- 原件哈希变化、数据不完整、错误柱形、金额篡改、普通表格兜底均不能发布。
- 受管路径以结构化终态阻断外层兜底；旧导出器也禁止将明确未完成警告编译并包装为成功。
- 旧完成判断不再接受早于本轮开始的共享index.html。
- 移除标准柱状图不必要的自由文本规划调用；不增加模型抄写数据或收尾HTML生成调用。

## 证据

- `tests.log`：59项相关回归全部通过，包含9项新增回归：旧共享文件、同session多轮、跨session、
  正负零值、表格/元数据/柱形篡改、两次修复、来源变化、核算失败后修正继续生成、失败导出阻断、
  不完整证据/澄清不能当作图表数据、旧index不能结束阶段、输入Excel文件名与输出格式路由边界。
- `runtime-smoke.py` / `runtime-stdout.log` / `runtime-verification.json` / `live-model-metrics.json`：
  原用户沙箱新进程，用原Excel副本执行真实dsh+模型端到端测试，原件和预放旧index均未变，7部门柱状图完成发布。
  实际首次聚合缺少file_path，模型下一轮修正成功；随后由runtime_workflow渲染，无bash执行。
  runtime约34.994秒，6次LLM、29184tokens；包含一次原有语义门禁超时回退，不把单次耗时作为稳定性能基准。
- `native-final.py` / `native-final.json`：最终版本在原沙箱新进程无模型调用复核，包含全部最终模块哈希，
  与本地源码一致。真实模型测试后的小幅调整（HTML数据节点编码、补充calculated状态与输入文件名路由）由此及回归覆盖。
- `verified-bar-chart.html`：最终版原始数据样本，7部门金额与21:22独立审计结果一致。
  浏览器确认7个SVG柱形、7条表格行、chart-data可解析、外部资源数0。窄屏可横向滚动。
- `sample-chart.html`：最初真实模型端到端生成样本，保留作为原始执行证据。

## 生效与边界

源码通过只读挂载进入用户沙箱，每次dsh启动新Python进程。沙箱因空闲停止后已启动，并用新进程确认
实际挂载指纹；未重建服务。未修改原用户附件、原21:22的index.html或已有会话记录。

仅对标准柱状图接入此状态机。显式Excel/Word/PPT/PDF输出、多种混合图表和复杂自定义页面仍走既有流程。
manifest保留恢复信息，本轮未实现跨进程自动恢复调度。完整通用工作区隔离及通用artifact API迁移不在本轮范围。
