# 部门别有偿统计

按已确认的业务逻辑与规则处理新附件，自动化执行“部门别有偿统计”。

## 1. 业务目标与触发场景
- **业务目标**：按照 部门编号 分组统计金额 的合计， 不包含WBS编号 中ex，sy，sp，ip，ib，sz开头的数据
- **触发意图**：当用户上传相关业务附件并提出类似“用部门别有偿统计处理”或“按部门别有偿统计要求统计”时触发。

## 2. 业务规则与处理口径
- 按照 部门编号 分组统计金额 的合计， 不包含WBS编号 中ex，sy，sp，ip，ib，sz开头的数据

## 2.1 用户确认的边界纠偏与排除规则（负向约束）
- ⚠️ 纠偏要点: 按照 部门编号 分组统计金额 的合计， 不包含WBS编号 中ex，sy，sp，ip，ib，sz开头的数据

## 3. 输入要求与参数化规范
- **输入附件**：新上传的同构业务文件（如 Excel / CSV / 报表）。
- **去硬编码原则**：严禁固化原文件名、固定数据行号或旧历史数字；对新输入文件必须重新扫描表头与有效数据区域。
- 详细结构化规则可参考 `references/rules.json`。

## 4. 执行机制
本技能为规则说明型个人技能，沙箱 Agent 读取本说明后根据规则自主进行数据分析、脚本编写与结果交付。

## 5. 输出约定
- 本技能无需生成独立物理附件，处理结果根据业务规则在沙箱中以文本或结构化数据直接呈现。
