## 仍需修复

1. **AI 清洗工程链路 401。** 复现：公司盘目标测试文件 → AI 清理 → 特定业务数据与参数抽取 → 要求保留六项事实 → 执行。抽屉显示“AI 清洗未能成功响应，已降级为规则启发式摘要”，列表仍未清洗，覆盖率 0%。后端日志明确记录 `Request failed with status code 401`。`workspace-digest.service.ts` 的 `extractDigestWithAi` 调用 `/ai/chat` 时请求配置仅有 timeout，未附认证头；应优先检查服务间认证传递与接收端鉴权。401 属工程调用失败，不能归因于模型摘要质量。
2. **知识上下文/问答遗漏原文关键字段。** 新会话，企业协同，联网关、知识开，提问“星桥管理闭环AD1015的项目预算、负责人和验收口令分别是什么？请附资料来源。”首次出现模型流连接失败，点击重新尝试后回答预算 52931 元、负责人测试员丁，但称口令未提及。点击同一来源可见口令 AD-Q8VN-6173。该问题不能据此直接判定为模型错误：当前知识注入以命中片段及摘要为主，应核对检索片段覆盖、截断和模型实际收到的上下文，再区分检索遗漏与模型遗漏。
3. **连接稳定性观察。** 首次原生问答报 `OpenAI API Stream Error: Connection failed`，重试成功；属于一次实际异常，尚不能断言稳定复现。历史中失败与成功重试均保留。
