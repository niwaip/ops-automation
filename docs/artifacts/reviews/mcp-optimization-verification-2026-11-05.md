# MCP 调用、来源与性能优化验证

## 完成内容

1. **契约前置约束**：个人沙箱只有读取单工具参数契约后才能得到短时签名凭据；凭据绑定用户、模式、工具、连接版本及 Schema 摘要。模型不可见凭据，服务端再次验证。猜测工具 ID、跨用户、篡改及过期均被拒绝。
2. **连接和重试**：同一 SDK 会话完成远端 Schema 复核与工具调用，避免重复初始化。只读网络/超时故障最多重试一次，单次上限 15 秒；写入和未知副作用不自动重试。失败保留安全的 connect/discover/invoke 阶段及类别，不暴露远端错误原文或凭证。
3. **来源和上下文**：MCP 文档 JSON 去重和限量披露，避免 content 与 structuredContent 重复进入模型。正文读取支持带网站横幅的 Markdown。来源从本轮成功调用结构化证据生成，按回答引用筛选；不使用环境扫描的成果库条目冒充来源。
4. **答案依据**：文档类答案增加一次不超过 20 秒预算的原文依据审核。要点必须对应有效来源和可定位的原文引句；不能核验时收窄回答或拒绝把草稿当作已核实配置指南。当前实现记录要点、URL、调用 ID 与引句，便于后续审计。未在用户输入或本轮证据中出现的 UUID 类配置值会被隐藏。
5. **准入**：只读 MCP 的 metadata 标明 read_only，进入既有只读准入快路径。含写入或未知副作用的连接继续使用原有准入与确认，执行时仍重新校验权限。
6. **模型容错**：fallback 抽成独立策略，最多 2 个候选；排除明确无凭证及输入/输出能力不匹配项；失败客户端短时冷却。缓冲流遵守配置的重试上限，fallback 流保留工具调用元数据。
7. **测试连接**：admin 的 Microsoft Learn 测试连接新增官方只读 microsoft_docs_fetch，允许按需获取正文。没有修改管理员模型配置，没有修改原聊天消息。
