# 工数表操作 E2E 测试政策

真实浏览器、个人模式、系统35B模型。用例在执行前生成，正确答案只在独立测试端持有，不提供给模型。数据读取、筛选等均从原附件进行；修改、删除和插入只授权新副本，原始附件和先前财务测试文件不得覆盖。

分别记录处理是否安全、需求是否全部完成、已交付数据是否正确。CLARIFICATION、SAFE_RETRY、PARTIAL_VERIFIED 均可为正常处理，不因单次没完成判失败。已交付部分同样需要准确。WRONG_DATA、FALSE_SUCCESS、SOURCE_MUTATION 为阻断；真实服务/锁/网络故障单独归因。

10项能力见 cases.json：K01范围/基础汇总；K02多条件筛选/排序/原行号；K03员工聚合/Top N；K04交叉汇总/占比/总量勾稽；K05全行重复与空值；K06日期粒度缺失；K07精确匹配/零结果；K08 UTF-8 CSV下载；K09副本增删改/向下填充公式/冻结/筛选/数值格式/条件格式；K10汇总公式/总体比例/图表/下载。

K04为交叉汇总结果验证，不将静态交叉表冒称原生Excel PivotTable。高级宏、外部连接、多文件连接和并发协作不在本轮覆盖范围。未生成文件或未执行的能力列为未验证，不能算作功能通过。

数据基准由 bundled Python + openpyxl 只读加载原件，用 Decimal 精确汇总。记录数、标识符、行号、分类精确匹配；工数与金额按原值校验，显示允许按声明精度舍入。金额仅称K，不推断币种和职级单价计算公式。年月字符串不能当每日日期；无客户名称只标缺失，不自动判为业务错误；员工编号重复不代表重复业务行。

下载CSV检查编码、表头、全部19字段、行号、筛选集合和排序。下载编辑副本逐行核对18原字段和授权的三项变更，验证公式文本及缓存/重算结果，再检查冻结、筛选、数值格式和条件格式。汇总文件核对全部7部门、SUM合计、整体占比公式、图表分类和数据源。文件存在或零公式错误均不是数据正确性的充分证明。

每个案例最多一次针对性补充；不为追求完成率无限重试。结束前刷新历史，复核下载内容与输入哈希。保留每轮请求、SSE与工具证据。生成和验证测试文件不修改产品业务代码。
