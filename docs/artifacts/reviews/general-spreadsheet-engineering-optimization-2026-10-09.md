# 通用表格分析工程优化验证（2026-10-09）

本轮增强通用只读分析链路，不按固定问题、工作簿名、Sheet 名或预设数值返回答案。模型仍负责语义和来源选择，程序负责执行、证据验收与数值交付。

## 已落实的改动

- **统一范围元数据**：正常与流式工作表共用 `worksheet_metadata.py`。缺失 producer dimension 时计算实际范围，不能用 A1:A1 占位；稀疏表头与样本保留空列位置。目录提示要求用途说明来自实际标题和字段。
- **比较结果由回执交付**：`comparison_delivery.py` 验证当前来源哈希、任务口径、指标与声明分组范围，从回执生成极值和并列结果。差额、绝对差额、相对差额、排序值及源坐标分别呈现，模型正文中的额外排名、数字和原因不进入数值报告。比较新增计划哈希、证据 ID 和精确十进制值，失败回执保留完整请求计划。
- **按实际能力构建提示词**：工具选择先于提示词组装；原生分析共用 `select_analysis_tools` 选择规则。用户提示列出本轮实际能力，只读核算不要求未提供的 bash，执行层继续拦截越权工具，拦截结果也进入归档。
- **逐轮证据与独立任务状态**：`evidence_store.py` 原子保存 `<session>.evidence/<turn_id>.json`，兼容侧文件保留最新轮。保存完整回执、错误、原件哈希和门禁状态，下一轮不覆盖归档。历史任务上下文独立于上游 role/content 同步；按当前附件与实际原件哈希校验、限量注入，不把历史事实当作本轮完成证据。最后一次拒绝不会继承此前通过状态。
- **按需读取结构**：新增 `inspect_spreadsheet_structure`，可展开指定的 1—4 张真实 Sheet，不重算。初始上下文保留紧凑表头、候选范围、行标签与单行样本，结构不足时才展开；结构回执不能满足分析完成门禁。
- **交付去重与聚焦**：相同来源、实际行范围、表达式、单位及语义 ID 的事实只展示一次，保留所有证据 ID；呈现顺序依据回执获取顺序。字段规则报告只展示被检查字段的概况，完整概况仍保留在回执。未成功的后续计划明确标出。

## 验证结果

- 292 项针对性与已有回归测试通过；新增测试覆盖非财务实验数据、稀疏列、缺失范围元数据、来源变化、失败状态、原子归档、多轮历史替换、证据去重，以及不同模型正文不能污染比较报告。
- 编译检查与 `git diff --check` 通过。
- 所有 Docker 校验通过仓库根目录 `./docker/start-smart.sh` 执行。运行中的用户沙箱有 38 个相关 Python 模块与仓库哈希一致；运行时 XLSX Skill 与独立财务参考文件也一致。
- 当前运行方式为源码只读挂载、每次 CLI 请求新建 Python 进程；本轮通过实际沙箱加载新代码确认生效。
- 本工作簿初始来源上下文由 14,785 降至 9,135 字符，减少 38.21%。这是字符长度结果，不推定模型 token 或延迟一定同比下降。
- 十张 Sheet 返回实际结构范围；例如《月度经营》A1:N16、《交易明细》A1:K83，不再全部报告 A1:A1。
- 沙箱财务核算、非财务实验合格率计算、预算列比较、单 Sheet 按需结构展开，以及两轮隔离会话归档均通过。比较报告保留净利润差额 -445.6875 与绝对差额 445.6875。
- 原工作簿哈希保持不变。运行时测试使用临时隔离会话，没有覆盖用户原有会话证据。

## 边界

这些机制提高来源、执行和交付的可验证性，但计算成功不能独立证明模型选择的未知业务含义正确。通用 Excel 适配层与可选 finance/commerce 语义包仍独立；需要强语义保证时，通过领域定义、稳定指标 ID 和实际来源绑定扩展契约。

本轮未调用随机模型问答重放，稳定性结论来自确定性边界测试和运行时核验。逐轮归档适用于后续执行，旧轮次未保存的完整回执不会被自动恢复。
