# 20:33 PDF 参数失败与修复

会话：`chat-session-1793277086853-956foavs`。请求未指定单页。

## 原因

三次调用均止于输入校验：第一次 pages 是序列化字符串，而且内部存在无效引号（JSON 第 2367 列）；第二、三次是四项正文加末尾空字符串。统一错误未指明类型和无效项，模型重复携带空项，触发三次同类错误停止。此阶段没有执行 PDF 渲染，不能归因为字体或排版失败。

## 修复

新增独立 pdf_page_input 模块，只解码有效 JSON 数组并删除末尾空白字符串；原始参数和修复动作保留在 attempt 审计记录。中间空页、全部为空、非字符串项及超限输入继续拒绝，并指明错误位置。不猜测修补损坏的 JSON，不删除任何非空内容。归一化后继续执行用户页数约束与原有内容、字体、视觉验收。

工具 schema 强调提交实际数组、禁止尾部空字符串；元素添加 minLength。生产 src bind mount 直接加载源码，按 full 入口重启 session-broker。
