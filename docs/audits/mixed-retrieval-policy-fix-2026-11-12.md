# 个人资料与联网混合检索修改及验证

## 修改结论

已将来源决策、候选筛选、查询计划与部署证据检查拆为独立模块，接入现有 dsh 生命周期与工具循环。个人资料仍只使用个人空间原件，没有恢复旧镜像扫描。当前开发环境通过源代码挂载供每个新 dsh 进程加载；实际调用已验证生效，未重启无源码变更的 Node 服务，也未中断其他用户任务。

规则如下：

- 显式联网执行网页检索；“不联网 / 只根据我的资料”关闭网页工具；“只联网”不扫描个人资料。个人空间里的“搜索”不再被当作显式外网要求。
- 公开技术部署、版本、选型、兼容性等问题可主动前置联网。纯附件处理和未明确搜索的文档生成保持任务范围；已选连接工作流不被自动网页检索替代。稳定概念问答无需因为包含 Docker 等产品名就强制查网。
- 首轮至多 Top 5，共享主题特征排序，按文档内容哈希/URL 去重，兼顾个人约束与部署手册，并对重复站点降低优先级。常用中英技术名词可以对应，通用 AI 词不能把算力部署页面当作 AI 网关证据。无固定本地/网页配额，后续工具读取不限于这五条。
- 前置缺少相关网页或安装参考时，剩余时间足够则进行至多一次定向补查。来源/任务方面齐全只意味着候选覆盖，不意味着事实正确性已经验证。
- 删除“个人资料优先”与“网页唯一事实依据”的冲突。个人环境、内部约定依据原件；公开版本、安装与兼容要求优先采用适用版本的官方资料。
- 部署命令/YAML 与引用链接若没有本轮成功资料支持，共用一次纠错机会。仍无支持时省略代码块或引用条目；可识别的个人文档引用修正到原件界面链接。最终来源附录只展示正文实际引用或点名的资料。

## 验证

76 项测试全部通过，包含路由边界、Top 5、重复来源、主题过滤、缺失安装资料补查、代码/引用纠错预算，以及既有网页、个人原件、规划与答案交付回归。新增循环集成测试确认纠错后仍无依据的命令被省略，不执行部署操作。`git diff --check` 通过。

通过仓库根目录的 `./docker/start-smart.sh dev exec -T session-broker ...` 执行所有沙箱测试与探测。可复现驱动和原始记录位于 `docs/artifacts/reviews/mixed-retrieval-20261112/`。

### 自动混合调用

验证会话：`audit-mixed-retrieval-20261112-auto-final`，问题“AI网关有哪些，如何部署”，没有“联网”指令。决策为 `public_technical`；个人资料命中 3 份，首轮实际选择 3 份个人资料与 2 份网页资料。后续模型继续定向搜索部署信息，触发一次部署纠错，最终省略 3 段仍未获资料支持的代码。

Broker 耗时 85.584 秒，模型 4 次调用，记录网页工具调用 5 次。补查增加了时延与 token 开销，不能将此结果描述为全程单次检索。首轮不含通用 AI 算力页面，且没有同站点占满候选。

此调用暴露了模型编造部分引用的情况。随后加入引用检查，并以该调用原始回执和实际答案确定性回放：修复原件引用、移除无法追溯的条目后，未追溯引用从 4 处变为 0，保留真实个人空间界面链接。引用检查最后这一步经过真实记录回放与回归测试，未再次发起一整轮相同的联网模型调用；不能把较早原始回答当作最终引用检查后的新模型输出。

### 不联网调用

验证会话：`audit-mixed-retrieval-20261112-local-only`，问题“不要联网，只根据我的资料说明AI网关的用途”。运行最终代码，决策为 `user_local_only`，网页工具调用 0 次，Broker 耗时 9.366 秒。

## 验证边界

主题评分与安装参考识别是轻量特征检查，并非语义重排模型。文档路径只是排序提示，不能独立证明官方身份。代码检查基于文本支持；引用检查基于链接来源，无法证明每项陈述、版本兼容性或所有部署步骤语义正确。没有在真实目标环境执行任何网关部署。模型仍可能在无代码、无引用的自然语言中产生错误，需要进一步的回答质量评测。

## 测试隔离事件与处理

首轮既有网页回归被历史 Excel 文件干扰，触发 4 个临时工作副本的重算。第二次仅设置 `WORKSPACE` 仍不够，因为旧 completion evaluator 独立读取 `WORKSPACE_DIR`。已修正网页测试夹具以临时目录替换其默认路径，验证驱动同时隔离两个环境变量；后续全部测试不再扫描用户目录。

个人空间正式原件始终未修改。4 个临时副本已从对应个人空间原件恢复并核对 SHA-256；误重算副本和恢复清单保存在审计目录，不参与检索。没有测试前临时副本的字节快照，因此这里的“恢复”明确指恢复为当前正式原件，不声称与测试前临时文件逐字节一致。原上传文件及其输入备份没有改动。
