## 1. 结论

**最终阻断的主因是工程侧的公式抽取污染和数字校验误判；同时存在模型翻译错误、校验漏检及无针对性的恢复。** 不能将本次失败简单定性为“模型把原文数字翻错了”。

第 7 页原稿的两个求和符号被原生抽取器输出为 `(cid:80)`，并混入普通段落。数字校验把该字体字符编号 `80` 当作应保留的事实数值。模型将其恢复为 `∑` 或 `Σ` 后，程序反而报 `numeric values changed`。离线重放四份 `p7_b2` 响应，均复现拒绝；仅在诊断输入中将 CID 标记替换为求和符号，四份均通过现有校验。此操作仅用于归因，未改写用户检查点，亦不代表译文整体通过语义验收。

任务停在 **translate 阶段**，没有生成候选 PDF，也没有进入逐页视觉验收。“完整性或页面验收”是通用失败文案。未发布未完成文件的行为正确，但触发文本校验失败的依据存在缺陷。

## 3. 最终错误的证据链

### 3.1 来源在翻译前已被污染

查看完整第 7 页原始渲染，原稿公式为：

- `SCORE = ∑(ℓ=1 到 L_reached) 100a_ℓ`。
- `EFFICIENCY = [1 / (T_max S_final)] ∑(t=1 到 T_max) S_t`。

`source.ir.json` 中两者均是 paragraph 节点，公式没有独立保护；抽取分别包含 `(cid:80)L reached` 和 `(cid:80)T max`，上下标、分数也被摊平并错序拼接。`native_parser.page_lines` 直接使用 `pdfplumber.extract_words` 的字符串，没有恢复这两个未映射字形。乱码随后作为不可变来源传入翻译。

`translation_validation.numbers` 用 `\d+(?:\.\d+)?` 抓取所有数字，未排除 CID 字符编号，也不区分数学结构和正文事实。

### 3.2 四次 p7_b2 响应的拒绝都包含伪数字 80

| 尝试 | 保存的译文公式 | 原校验认定的数字缺失 |
| --- | --- | --- |
| 首次翻译 / 批次 8 / 1 | `(1/T_max) ∑(t=1 到 T_max) (S_t/S_final)` | `80` |
| 首次翻译 / 单段重试 | `1/T_max * Σ(t=1 到 T_max) (S_t/S_final)` | `80` |
| 恢复翻译 / 批次 1 / 1 | `(1/T_max) ∑(t=1 到 T_max) (S_t/S_final)` | `80` |
| 恢复翻译 / 单段重试 | `∑(t=1 到 T_max) S_t / (T_max*S_final)` | `80`、`1` |

前三次并没有丢失真实的正文数值；最后一次把分子 `1` 吸收到整个分式，公式在数学上等价，数字出现次数却发生变化。现有校验在诊断去掉 CID 后也接受最后一次，但这是因为译文里有“一次”等文字，触发中文数词的宽泛豁免，**不是因为系统理解了公式等价**。

### 3.3 存在真实模型错误和反向漏检

- 首次翻译的 `p7_b1` 单段重试凭空增加“第 100 级”，原文只有“在该级获得 80 分”。这是确定的模型错误，被门禁拒绝。
- 恢复翻译的 `p7_b2` 批量响应把“跳过层级不增加训练阶段计数”译成“跳过的层级在增加计数的同时获得分数”，语义相反。数字校验无法识别此错误；因此不能因去掉伪数字就放行该响应。
- 最后被接受并存入检查点的 `p7_b1` 保留了 `(cid:80)`，公式变成 `SCORE = (cid:80)L 100a ℓ`，丢失求和下限 `ℓ=1` 和完整上限。其 `errors={}`。缺失的 `1` 被段落中无关的“一”豁免。**错误公式得以通过、正确公式却被拒绝，是校验规则缺陷的直接证据。**

代码位置：`native_parser.py:69` 的原生行抽取；`translation_validation.py:36` 的数字提取、`:99` 的中文数词豁免；`text_translator.py:76` 的接受/拒绝写入。

## 4. 为什么恢复没有解决

`translate_document` 每批先翻译一次，再对失败 ID 各做一次单段重试。外层 `recover_pdf_translation` 分别允许布局和翻译各恢复一次，所以本轮是三个 Job，而不是没有重试。

但单段重试仍使用相同来源和通用提示；`_build_translation_prompt` 的 `feedback` 参数没有被使用，失败原因、上一份译文和具体数字差异没有传入。翻译恢复也只重新验证来源和复用译文，没有恢复 CID 字形或保护公式。四次都要求模型面对同一损坏输入，最终耗尽恢复机会。

最后检查点共有 845 个应有文本单元，只保存 476 个门禁接受值，其中 405 个是不需翻译而复制的字面值，71 个需翻译单元有保存结果；另有 369 个单元没有保存译文。第 7 页失败使后续批次未完成接收处理。上述数量不是人工语义验收结果；已保存值中也包含前述公式漏检。

因此，“第 7 页段落”是当前首个阻断位置，**不代表全书其余段落都已翻译完成**。
