## 修复边界

- **分页输入**：未明确要求页数时，工具 schema 优先 markdown 连续正文。兼容 pages 时按正文块自然流排版，不对每个标题/段落强制分页；忽略模型自行指定的页数范围及分页标记。明确页数请求继续保留严格分页。归一化和分页策略写入 attempt 记录。
- **表格结构**：flow_markdown_chunks 连接分散的管道表格行，检测新表头分隔行，避免将相邻两张表合并。不是简单地把数组以空行拼接。
- **故障分类**：有效 REPAIR/FAIL 为内容问题；空响应、无效审阅协议、网络/超时为 pdf_review_unavailable；哈希/版本/文件状态异常为 pdf_review_state_invalid。后两类停止正文重写。通用检索 Agent 与 owned-content 两个入口均处理这些终止结果。
- **有限恢复**：同一页最多两次请求，单次20秒、单页40秒；保持候选和正文不变。环境故障后打开本轮熔断，换文件名也不会再发请求。每个目标最多3个内容修复审阅版本；所有目标共享本轮120秒验收窗口，换文件名不能重置。继续沿用全局长任务策略，不重新引入全局默认300秒限制。
- **队列/可观测性**：每批最多2页，失败批次完成后停止后续队列；逐批写入模型账本和执行结果，不等几十页检查完才登记。控制台和前端显示实际验收页码、通过/未通过，渲染结束不表示已交付。
- **模型代理**：显式 vision 能力路由；回退保留 thinking=false、token预算、工具参数；响应保留真实模型名、finish_reason、reasoning和tool_calls。拒绝空正文的视觉伪成功；不把未确认视觉能力的默认文本客户端列为视觉兜底。新增独立 sandbox-completion-response 模块承载响应契约，避免继续向控制器内堆细节。
- **传输诊断**：HTTPError 必须在其父类 URLError 前处理，保留真实上游错误；遥测记录实际回退模型。截断和空响应不会冒充页面内容缺陷。
