# PDF 模板执行优化与验证（2026-10-29）

正式 broker 复测成功：使用原始《城市自然观察手册》请求、同一默认 `qwen36-35b-a3b` 模型，约 **47.8 秒**完成两页 A4 PDF，包含一次内容渲染、两次本轮页面视觉检查与最终发布。原调用在 300 秒后失败。

原调用时间是前端 HTTP 全程；本次计时从编排容器调用正式 broker 到收到结果，包括锁、容器准备、DSH 和模型代理，不包含浏览器与聊天入口。它是一次成功样本，不是稳定 SLA 或所有 PDF 的成功率承诺。

## 实施内容

1. **受管模板路径。** 普通新建 PDF 使用 `render_pdf`，模型提交 Markdown 与参数，固定生成器负责字体、版式和检查。跳过独立长规划；不把“时间天气”记录卡当成实时天气查询。转换、表单、附件/统计/图表、混合格式、多份具名 PDF 和指定其他引擎继续走原工具链。
2. **缩小模型决策范围。** 原生流程明确选择渲染函数，使用简短执行规范，避免 CLI 和示例正文与用户需求竞争。渲染成功后运行时直接逐页检查，无需额外模型轮次来猜选预览路径。
3. **绑定用户明确要求。** 绑定文件名、页数、版式、暖色、无封面、标题/副标题/署名。对支持的逐页文字结构核对表头、对象、记录卡、插图、问题数量、准备清单和记录方法，阻止压页时删掉指定内容。
4. **规范打印版式。** handout 正文保持 11.5pt，使用 1.5 倍行距；调整章节、表格和本地叶片尺寸。去除重复元信息、未经要求的 emoji、手工换行标签和重复装饰线，将旧提示块写法转为受支持的浅色引用块；保留表格语法和填写用下划线。没有通过放宽页数或不断缩字号完成交付。
5. **验收前不发布。** 先生成隐藏候选与唯一 QA/PNG，按本轮回执取图并核对 PDF 哈希。视觉检查失败不覆盖原件；全部页通过后才原子发布。终态回复由发布回执生成，禁止旧编译兜底在此路径放宽页数。
6. **失败与中止可追溯。** 同类字体/渲染错误达到阈值后终止无效重试。增量事件保存在 `.dsh/sessions/<session>.events/<run>.jsonl`，包含模型起止、工具起止、错误和阶段决定；强制停止前的事件仍可读取。
7. **取消传播。** 平台管理的模型请求绑定下游断开信号，经 OpenAI-compatible/Anthropic 客户端传给 HTTP 传输；取消后不再重试或切换模型。正常请求读完、正常响应关闭不会被误判为取消。

新增能力下沉到独立的 PDF 路由、内容约束、渲染适配、预览发布、执行日志和错误恢复模块。runner 仍为 1,200 行，agent loop 为约 1,070 行；未向超大入口堆入渲染或文件处理实现。
