# 23:04 PDF调用故障修复与验证

## 修复范围

在现有未提交实现上增量修复，未重置工作区或改动其他服务。

1. 新增native_graphic_recovery职责模块：在图注避让与边界收缩后，利用原PDF的独立、无文字冲突图像区域补回遗漏图形，并按栏/纵坐标插入阅读顺序。正文、表格或标签归属冲突仍交由布局重试；保留95%覆盖、正面积、最小尺寸等校验，没有放宽门禁。
2. 布局失败保存layout_ir_sha256检查点；auto --resume重新提取当前PDF的原生证据，核对输入/版本/IR哈希、原生行、图形边界、表格候选、逐页行归属与文字，复用连续通过页，仅分析后续页。来源或检查点变动明确拒绝；完整布局与译文恢复仍使用原严格检查。
3. 统一识别受限输出包装2>&1 | tail -N或tail -n N，使unpack/auto仍进入PDF专用预算、独立job、父账本及结构化错误。任意其他管道、tail -f或附带shell命令不获得此预算。CLI退出错误保留pipefail并返回checkpoint_incomplete等业务失败，不再被tail成功掩盖。
4. 回执明确给出可恢复目录或无检查点时的停止/重解析指引；SKILL同步说明layout_unresolved恢复规则及禁止使用历史PDF。现有输入/run/job/candidate哈希绑定与历史产物隔离门禁保留。
