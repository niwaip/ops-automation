## 复测中补齐的链路

第一次探索复测虽然有正文，但 `answerValidation={}`。原因是思考规划阶段自行完成了搜索，原始回执未传到执行阶段。该次不作为正式验收通过，证据保留在 `initial-e2e.*`。

修复后，前置搜索、规划与执行循环都传递本轮 ToolResult 回执；规划资料还会在总字符预算内传给呈现阶段。规划独占搜索、执行阶段不搜索的路径由实际容器内集成回归覆盖。

## 运行与变更边界

- Python 模块经 `${PROJECT_ROOT}` 源码挂载，新 dsh 进程实际导入验证通过，无需重启未改动的常驻 Node 服务。
- 最终回复职责从 `agent_loop.py` 下沉到 `final_answer.py`，循环文件减少 200 余行，兼容已有入口。
- 原始用户指令显式传入循环，避免检索资料与呈现指令被识别为任务契约；有专项回归验证用户只要标题时不会被强行补全文本。
- 未覆盖原始用户会话、未切换用户选定模型、未提交仓库中其他既有改动。
- 其他未使用源码挂载的环境仍需更新镜像并重建沙箱；本报告只确认当前本地环境。
