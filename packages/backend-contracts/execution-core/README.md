# `execution-core`

执行域共享核心契约包，用于承接执行状态、步骤状态、审批状态、事件类型与执行语义等稳定类型。

## Holds

- execution status constants and types
- execution step status constants and types
- approval status constants and types
- execution event type constants and types
- execution semantic DTOs and terminal-status helper

## Does Not Hold

- execution service logic
- runtime adapter implementations
- persistence models
- release-manager or registry behavior
