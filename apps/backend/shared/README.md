# Backend Shared Layer

公共共享层（Shared Layer）负责为所有后端服务提供底层的通用内核与工具基建，**禁止将这里做成不加限制的公共大杂烩目录**。

## 典型职责

- **契约中心 (Contracts)**：全局公共 DTO、Event 定义、服务接口契约。
- **基础内核 (Kernel)**：通用错误基类、结果对象模型、全局唯一 ID 生成规则。
- **适配与适配器 (Infra Adapters)**：数据库基础封装（如 Prisma 的通用部分）、Redis 连接助手、MQ 抽象适配器。
- **测试脚手架 (Testkit)**：单元与集成测试的基准 Mock 夹具。

## 规范约束

- 共享层不允许依赖上层任何服务。
- 引入新的共享能力必须经过严格的技术评估，以防层级退化与循环引用。
