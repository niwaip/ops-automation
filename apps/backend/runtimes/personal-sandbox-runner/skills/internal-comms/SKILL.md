# Enterprise Internal Communications Skill

本技能为智能体提供标准化的大厂级内部沟通与汇报规范。

---

## 1. 场景一：3P 周报 / 月报模版（Progress, Plans, Problems）

当用户要求写周报、月报或工作汇报时，统一采用业界公认的 **3P 框架**，拒绝流水账：

```markdown
# 📋 【研发/运维团队】工作周报 (YYYY-WW)

## 1. 🟢 Progress (本周核心进展)
- **【核心交付 1】**：完成 DeepSeek Harness 沙箱环境强化，支持 100% 离线 PDF/Excel 生成，吞吐提升 40%。
- **【核心交付 2】**：排查并根治个人空间流式状态双重渲染问题，前后端契约已对齐。
- **【指标变化】**：平均响应时间降低 150ms，线上可用率维持 99.99%。

## 2. 🔵 Plans (下周工作计划)
- **【计划 1】**：完成 6 个标准技能包（xlsx, docx, comms 等）的意图嗅探与自动化测试覆盖。
- **【计划 2】**：启动知识库全文检索向量化升级预研。

## 3. 🔴 Problems / Risks (阻碍与风险预警)
- **【风险 1】**：上游部分外网 API 存在间歇性 502 错误，需推进本地缓存与降级机制。
- **【协助诉求】**：需协调测试环境一台独立机器用于压力压测。
```

## 2. 场景二：线上故障复盘与事件通报（Post-Mortem / Incident Report）

```markdown
# 🚨 【故障通报/复盘】[等级: P1] [系统名称] 接口响应异常事件报告

## 📌 事件概览
- **故障等级**：P1（核心服务降级）
- **影响范围**：约 5% 的用户在导出 PDF 时出现脚本报错
- **起止时间**：2026-09-06 22:20 ~ 22:45（持续 25 分钟）
- **当前状态**：已止血恢复，相关补丁已验证上线

## ⏱️ 事件时间线 (Timeline)
- **22:20**：用户反馈输入“1”后控制台输出包含 || 的未执行脚本。
- **22:25**：值班人员响应，定位为模型生成脚本时外网字体下载中断。
- **22:35**：部署离线思源黑体资产至沙箱，并配置专属 PDF 技能规约。
- **22:45**：全链路回归验证通过，业务恢复正常。

## 🔍 根本原因 (Root Cause)
缺少标准化 Skill 约束，导致模型临场尝试联网下载外部依赖；在受限网络环境下命令被截断形成语法错误。

## 🛡️ 止血措施与后续改进项 (Action Items)
1. ✅ [立即] 预置全套离线中文字体至 `/opt/dsh/skills/pdf/assets/`。（Owner: 运维组）
2. 🔄 [本周] 引入 `xlsx`、`docx`、`internal-comms` 等标准企业技能库，杜绝临时联网操作。（Owner: 基础架构）
```

  1. 新增 Excel、Word、PDF 深度离线处理技能
