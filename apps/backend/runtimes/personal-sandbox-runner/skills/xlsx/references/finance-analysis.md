# 可选财务分析方法

本参考属于 `finance` 领域，不是 Excel 文件的必选规则。运行时定义位于 `analysis_domain_finance.py`，表名、范围、列和答案均不写入领域定义。

- 盈利能力概念要求收入、毛利、营业利润、净利润及对应利润率。期间利润率采用汇总利润除以同期间汇总收入；逐月平均比率不能替代此口径。
- 变化分析须有不同期间的对照，并分别说明金额变化和比率变化。数值关系由程序验证，经营原因需要额外证据。
- 跨表等式必须说明主体、期间、符号约定、调整项和容差。等式残差不直接证明某张表的公式错误。
- 异常金额、日期、审批状态等检查调用通用字段规则。阈值与允许值需要来源依据；缺少依据时使用全列概况列出核查线索。
- 领域注册表提供标准指标 ID 和定义；模型将自然语言转换为显式来源计划，不能用 ID 绕过字段或期间核验。

财务核算口径可能随企业、行业和准则而不同。领域包需按适用业务版本维护；这里的通用利润率关系不等同于完整会计政策库。
