# audit-policy

当前目录代表未来 `governance/audit-policy` 的统一逻辑视图。

本目录用于承接平台级审计、发布合规与全局策略边界，
把这类横切治理能力从具体业务模块中抽离出来。

## 该目录负责

- 平台级审计记录模型与归档边界
- 全局策略、合规规则与风险分级
- 发布与执行前的治理侧约束表达
- 面向治理平面的共享策略对象模型

## 该目录不负责

- Skill / Workflow / Template 的设计时管理
- Execution 生命周期推进
- 单个 capability domain 的内部业务实现
- Worker 侧原子执行

## 当前迁移状态

- 当前先落最小源码入口与治理对象模型。
- 旧的发布审计与局部校验实现，仍可能分散在 `core/platform` 或 `registry-release` 过渡层。
- 新的审计记录、全局策略与合规约束模型，应优先收敛到本包。
