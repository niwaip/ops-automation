Template Syntax Guide

Variable Syntax

Use {d.variableName} to insert data into your template.

Hello {d.name}!
Total: {d.price}
Date: {d.date}

Formatters

Chain formatters with : to transform values.

{d.price:formatNumber(#,##0.00)}
{d.name:upperCase}
{d.date:formatD(YYYY-MM-DD)}
{d.total:round(2):currency($)}

Available Formatters

Array Loops

Use [i] and [i+1] to create repeating sections.

<tr>
    <td>{d.items[i].name}</td>
    <td>{d.items[i].price}</td>
</tr>
<tr>
    <td>{d.items[i+1].name}</td>
    <td>{d.items[i+1].price}</td>
</tr>

The content between [i] and [i+1] will be repeated for each item in the array.

Conditional Display

Show or hide content based on conditions.

{d.isActive:show(Active)}
{d.isDeleted:hide(Not Deleted)}
{d.status:if(Active, Inactive)}

Nested Objects

Access nested data with dot notation.

Company: {d.company.name}
Manager: {d.company.manager.name}
Email: {d.company.contact.email}
