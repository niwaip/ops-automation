加载步骤

  1. 点击上方卡片下载 manifest 文件
  2. 打开对应的 Office 应用（Word/Excel/PPT）
  3. 点击 插入 → 加载项 → 我的加载项
  4. 点击 上传我的加载项
  5. 选择下载的 manifest 文件

MacOS 信任证书

首次使用需要在系统中信任SSL证书：

sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain /path/to/server.crt
